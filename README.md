# パーソナルニュースアプリ α版

公的機関・企業などの一次情報を扱う個人用ニュースアプリのα版です。公式サイトの RSS/Atom からニュースを集め、カテゴリ別に一覧表示し、記事を開くと発信元ページから抽出した概要を表示します。

## 主要機能
- 上部のカテゴリタブ（トップ / 政治 / 経済 / 投資 / 社会 / 国際 / テクノロジー / 生成AI）。カテゴリごとに色分け
- 各タブで地域（すべて / 日本 / 海外）をプルダウンで選択。選択はタブごとに保持
- 日付ごと（今日・昨日・日付）にまとめた記事カード。先頭付近の画像付き記事を大きく表示
- 記事をタップすると詳細画面へ。**AI要約**（日本語の要約と要点）、本文の冒頭、「元記事を読む」ボタンを表示
- 「戻る」ボタン・ブラウザの戻る・iPhone のスワイプで、一覧の元のスクロール位置に戻る
- キーワード・ハッシュタグ検索、記事の共有（iPhone の共有シート）、ダークモード

## 実行方法
```bash
npm install
cp .env.example .env   # AI 要約を使う場合は ANTHROPIC_API_KEY を記入
npm run dev
```

ブラウザで `http://localhost:3000` を開いて利用します。iPhone からの利用方法は [IPHONE_SETUP.md](IPHONE_SETUP.md) を参照してください。

## AI 要約
- 記事を開くと、発信元ページの本文（PDF 資料の場合は PDF そのもの）だけを Claude（`claude-opus-5-5`）に渡し、日本語の要約と要点を作成します。英語の記事も日本語で要約し、見出しも日本語に訳します。
- 外部の知識による補足や推測はしないよう指示しています。それでも誤りを含む可能性があるため、画面上にその旨と元記事へのリンクを表示します。
- 作成した要約は `data/summaries.json` に保存し、同じ記事を再度要約することはありません。一覧のカードにも保存済みの要約が表示されます。
- `ANTHROPIC_API_KEY` が未設定の場合、要約機能はオフになり、本文の冒頭のみを表示します。
- 費用の目安: 1 記事あたり数円程度（本文の長さによる）。本文が非常に長い場合は先頭 60,000 文字までを要約対象にします。
- `.env` の `AUTO_SUMMARY_LIMIT` に件数を設定すると、一覧の更新時に最新記事のうち未要約のものを裏で自動要約します（既定は 0 = 無効。件数分の API 料金がかかります）。

## 情報源とカテゴリ
| カテゴリ | 日本 | 海外 |
|---|---|---|
| 政治 | 首相官邸、総務省 | 米国務省 |
| 経済 | 日本銀行、財務省、経済産業省、金融庁 | FRB、ECB |
| 投資 | GPIF、PR TIMES（資金調達などに一致した発表のみ） | PR Newswire（Venture Capital） |
| 社会 | 厚生労働省、文部科学省 | 米CDC |
| 国際 | JETRO ビジネス短信 | WHO、欧州委員会、英国外務省 |
| テクノロジー | デジタル庁、JST | NIST、NSF、NVIDIA |
| 生成AI | Sakana AI、PR TIMES（生成AI関連に一致した発表のみ） | OpenAI、Google DeepMind、Google |

上記に加え、見出し・説明文に含まれる語で次のように分類します（`src/newsPipeline.ts` の `CATEGORY_RULES`）。
- 「資金調達」「シリーズA」「国内投資」などを含む記事は **投資** に入れ、経済からは外す
- 「生成AI」「LLM」「AIエージェント」などを含む記事は **生成AI** にも表示する
- 日本の情報源で「首脳」「外相」「国連」などを含む記事は **国際・日本** にも表示する

## 設計方針
- 一覧の説明文（100文字以内）は RSS の説明文をそのまま短縮したもの。AI 要約は発信元の本文のみを根拠に作成し、AI が作成したことを明示する
- ハッシュタグは発信元・カテゴリ・地域の事実のみから生成する
- 全文は表示せず、必ず「元記事を読む」から発信元で確認できるようにする

## 運用メモ
- フィードを追加・変更する場合は `src/newsPipeline.ts` の `officialFeeds` 配列を更新してください。
- フィードは10分間サーバー側でキャッシュします。取得はフィードごとに8秒でタイムアウトします。
- フィードに画像がない記事は、新しいものから順に記事ページの画像（og:image）を裏で確認し、サムネイルに使います（1記事1回のみ。サイト共通のロゴ画像は除外）。
- 取得した記事は `data/news-archive.json` に30日分蓄積します（PR TIMES のように新着の入れ替わりが速いフィードでも、一定期間分を表示するため）。削除すると次回取得分から作り直します。
- 全フィードの取得に失敗し、蓄積データもない場合のみ「サンプル」バッジ付きの記事を表示します（実在の発表ではありません）。
- 取得に失敗したフィードはサーバーのログに `[feed] 発信元名: 理由` の形式で表示されます。

## API
- `GET /api/categories` — カテゴリと地域の一覧
- `GET /api/news?category=&subgroup=&keyword=&offset=&limit=` — 記事一覧（総件数は `X-Total-Count` ヘッダー）
- `GET /api/news/:id` — 記事、発信元ページから抽出した本文の冒頭、保存済みの AI 要約
- `GET /api/news/:id/summary` — AI 要約（未作成なら作成して保存）
- `GET /api/config` — AI 要約が有効かどうか
