# パーソナルニュースアプリ α版

公的機関の一次情報を扱うニュース収集・要約アプリのα版です。RSS/Atomからニュースを収集し、要約（100文字以内）・ハッシュタグ生成・検索・カテゴリ別表示を行います。

## 主要機能
- カテゴリとサブグループの構造: 経済/社会/国際/政治 × 日本/海外
- 公式サイトのRSS/Atomを収集し、一次情報を基準に記事を整理
- 原稿要約を100文字以内に制御し、追加の外部情報を混ぜない設計
- ハッシュタグ生成（最大3件）とキーワード検索
- 最小構成のWeb UIを備えたアプリ

## 実行方法
```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いて利用します。

## 使い分け
- 収集の核は RSS/Atom の一次情報を維持
- 要約は title/description の事実をそのまま圧縮
- 解析対象の外部情報は使用せず、ハルシネーション防止を前提に設計

## 運用メモ
- 公式RSSのURLが変わる場合は `src/newsPipeline.ts` の `officialFeeds` 配列を更新してください。
- API では `GET /api/news` と `GET /api/categories` を利用できます。
