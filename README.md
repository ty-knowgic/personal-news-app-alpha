# パーソナルニュースアプリ α版

公的機関・企業などの一次情報を扱う個人用ニュースアプリのα版です。公式サイトの RSS/Atom からニュースを集め、カテゴリ別に一覧表示し、記事を開くと発信元ページから抽出した概要を表示します。

## 主要機能
- 上部タブでカテゴリを切り替え（トップ / 政治 / 経済 / 投資 / 社会 / 国際 / テクノロジー / 生成AI）
- 各タブで地域（すべて / 日本 / 海外）をプルダウンで選択。選択はタブごとに保持
- 見出しをタップすると詳細画面へ移動し、発信元ページの冒頭部分（概要）を表示。「戻る」ボタン・ブラウザの戻る・iPhone のスワイプで一覧のスクロール位置に戻る
- キーワード・ハッシュタグ検索（詳細画面のハッシュタグをタップしても検索できる）
- ダークモード、iPhone のホーム画面追加に対応

## 実行方法
```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いて利用します。iPhone からの利用方法は [IPHONE_SETUP.md](IPHONE_SETUP.md) を参照してください。

## 情報源とカテゴリ
| カテゴリ | 日本 | 海外 |
|---|---|---|
| 政治 | 首相官邸、総務省 | 米国務省 |
| 経済 | 日本銀行、財務省、経済産業省、金融庁 | FRB、ECB |
| 投資 | GPIF、PR TIMES（資金調達などに一致した発表のみ） | PR Newswire（Venture Capital） |
| 社会 | 厚生労働省、文部科学省 | 米CDC |
| 国際 | JETRO ビジネス短信 | WHO、欧州委員会、英国外務省 |
| テクノロジー | デジタル庁、JST | NIST、NSF、NVIDIA |
| 生成AI | Sakana AI、PR TIMES（生成AI関連に一致した発表のみ） | OpenAI、Google DeepMind、Google |

上記に加え、見出し・説明文に含まれる語で次のように分類します（`src/newsPipeline.ts` の `CATEGORY_RULES`）。
- 「資金調達」「シリーズA」「国内投資」などを含む記事は **投資** に入れ、経済からは外す
- 「生成AI」「LLM」「AIエージェント」などを含む記事は **生成AI** にも表示する
- 日本の情報源で「首脳」「外相」「国連」などを含む記事は **国際・日本** にも表示する

## 設計方針
- 一覧の要約（100文字以内）は RSS の説明文をそのまま短縮したもの。詳細画面の概要は発信元ページの本文冒頭をそのまま抽出したもので、要約や独自の解釈は加えない
- ハッシュタグは発信元・カテゴリ・地域の事実のみから生成する
- 全文は表示せず、必ず「元記事を読む」から発信元で確認できるようにする

## 運用メモ
- フィードを追加・変更する場合は `src/newsPipeline.ts` の `officialFeeds` 配列を更新してください。
- フィードは10分間サーバー側でキャッシュします。取得はフィードごとに8秒でタイムアウトします。
- 取得した記事は `data/news-archive.json` に30日分蓄積します（PR TIMES のように新着の入れ替わりが速いフィードでも、一定期間分を表示するため）。削除すると次回取得分から作り直します。
- 全フィードの取得に失敗し、蓄積データもない場合のみ「サンプル」バッジ付きの記事を表示します（実在の発表ではありません）。
- 取得に失敗したフィードはサーバーのログに `[feed] 発信元名: 理由` の形式で表示されます。

## API
- `GET /api/categories` — カテゴリと地域の一覧
- `GET /api/news?category=&subgroup=&keyword=&offset=&limit=` — 記事一覧（総件数は `X-Total-Count` ヘッダー）
- `GET /api/news/:id` — 記事と、発信元ページから抽出した概要
